# generalizations/

Instances of pm:Generalizing: statements formed from several attested claims
that no single source makes. They carry pm:generalizedFrom instead of
dcterms:source and belong to no tradition, which is why they live here and
not under traditions/.

Empty until the first generalization is written. The folder is wired into
compile.py, validate.py, publish.py and tests/test_no_substance_classes.py
so that the first file added is compiled and validated rather than silently
skipped (SPEC §9, Ordnerregel).
